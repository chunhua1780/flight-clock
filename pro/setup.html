Flight Clock — first-time setup

About 10 minutes, once. Your roster stays in your own Google account; nobody else can read it.

1. Put your roster in your Google Calendar

Subscribe or import your roster into Google Calendar (calendar.google.com) so that each flight is an event, e.g. EK0302 DXB-PVG.

2. Make your own backend (Google Apps Script)

  1. Open script.google.com with the same Google account → New project. Name it “Flight Clock”.
  2. Open this code file, select all, copy, and paste it over everything in Code.gs. Press 💾 Save.
  3. In the function menu at the top choose setup → Run. Allow the permissions (Advanced → Go to Flight Clock → Allow). This is your own script reading your own calendar.
  4. Deploy → New deployment → type Web app. Execute as: Me. Who has access: Anyone. → Deploy.
  5. Copy the Web app URL (ends with /exec). Keep it private.

3. Open the clock

  1. On the iPad open the Flight Clock in Safari → Share → Add to Home Screen.
  2. In ⚙︎ Settings enter your staff number, your activation code and the Web app URL from step 2.
  3. Tap Test — it should list your next flights — then Save.
Activation code
Each code works only with the staff number it was issued for. Contact the seller to get one.
