# Flight tools — handover (for a fresh session)

Owner: Emirates B777 pilot. Replies in Chinese, plain language. All times UTC. Everything is an awareness aid only.

## Repos and publishing
- `chunhua1780/flight-clock` = source. `chunhua1780/flight-cloch` = GitHub Pages site (published copy). Push both to `main`.
- `chunhua1780/flight-box` = PRIVATE cloud storage (OFPs, translations, DB). The backend writes it (via its GitHub token). Since 2026-11-20 it also holds the **cloud brief**: `.github/workflows/brief.yml` + `tools/brief.mjs` run on every push of `ofpdata/*.txt.gz` (or by hand: Actions → Cloud brief → only / force), open the public Flight Assist page in headless Chrome, load the OFP (+ `ofpdata/ZZEKTABLE.sb.html`), and commit `ofpdata/<k>.sb.html` + `<k>.full.html` with `sb` / `full` times in `index.json`. The phone panel downloads both (📋 short ⇄ 📄 full). Two weather versions: `.sb/.full` = OFP weather (rebuilt when the OFP changes), `.sbn/.fulln` = latest METAR/TAF from aviationweather.gov (hourly cron, flights from 20 h ago to 24 h ahead); panel 🌦 switches (`pnl.wxsrc`). Flight Assist has the same switch (🌦 in the brief bar, `fa.wxsrc`, also drives the alternate lists) and fetches latest weather for up to 12 OFP airports. Weather is judged over ±1 h of the passing / landing time (`WX.atWin`). The user allowed attaching it for this; never copy its contents into the public repos.
- Never put passwords, API keys, company manuals/OFPs in the two public repos. Grep before pushing.
- Publish steps:
  - Home clock: `V=$(date -u +%Y%m%d%H%M%S); sed "s/__APP_VER__/$V/g" ../flight-clock/app.html > app.html; printf %s $V > version.txt` (in flight-cloch).
  - Flight Assist (iPad, `/assist/`): bump `APPV 'vNN'` in assist/index.html and `fa-vNN` in assist/sw.js, copy changed files.
  - Panel (phone, `/panel/`): bump `pnl-vNN` in panel/sw.js, run `./panel/mkfiles.sh`, then `node tools/mkeink.js` (builds `/panel-eink/`, ES5 for old Android), copy panel files + panel-eink dir.
  - Backend: copy `apps-script/Code.gs` to flight-cloch `apps-script/Code.gs` and `Code.txt`; bump `BACKEND_VER`. The user's Apps Script runs a small **loader** (`apps-script/Loader.gs`) that downloads Code.txt (cached 1 h). Force reload now: POST `{"action":"reload"}` with `?k=<password>`. Check: `GET …/exec?action=ver`.
- Android APKs: `android/build.sh <keystore> <pass> <out.apk> [presetPassword]`; `VARIANT=eink` builds the e-ink app (net.flightpanel.eink, minSdk 19). Public APKs go to flight-cloch/panel/. Personal APKs (with preset password) are sent to the user only.

## Components
- **Home clock** `app.html`: calendar + ADS-B modes (home / flight / layover / turnaround); bold styling; clock colour picker in ⚙︎ (solid / rainbow / gradients, optional slow flow); home, layover and turnaround bottom row has a green "Back in Dubai" column (weekday, date, landing time of the next flight into base); version shown in ⚙︎. Airport data (`airports.json`, ~7900 airports) is cached in localStorage `fc.airports`, retried with back-off when the download fails, and the flight view falls back to the plan's first / last route points (`apLate()` reloads flights once the data arrives) — fixes "Unknown airport DXB / DPS". Shells (`index.html`, `lite/index.html`) swap in the new version in the background and reload the whole page if the swap has not happened within 2 min (2026-11-20).
- **Flight Assist** `assist/`: OFP parse, map, NOTAM translation (TR store, `s:<id>` = one-line summary), Today Brief (`brief.js`, uploads a copy for the phone via `CLOUD.sbUp`), logbook (`logbook.js`, Google Sheet sync), contingency (WAC), interview DB, upload pages `data.html` (JSON/CSV/Excel, formats: waypoints / areas / notams / procedures / reminders) and `fi.html` (review DB).
- **Panel** `panel/` (Hisense phone app + Yota e-ink app + iPad landscape): map with GPS (Android bridge `AndroidPanel.gps()`), FIR label, waypoint column, alert card, ZFW input + red max-fuel figure, timeline (STD−x), crew brief (STD−85…−80), reminder rules, briefing package (`pkg.js`, AI plain-Chinese per section, PDF via backend), logbook (CAAC / Jeppesen), shared flight state. Map colours: ⚙︎ → strong (default, for the Hisense A5 Pro CC colour e-ink, `html.cbold`) / light (old pale colours, same as the B/W e-ink palette). Crew brief: chip under the flight number from STD−113 to STD−60 with a countdown to STD−83 and a red `!`; tap → card with outbound + same-day return (flight time, levels, landing time, landing weather from the stored METAR/TAF). Flight-number bar stays plain black on white (user preference). Pre-departure timeline chip (`TLS` in panel/index.html, from STD−75 until off-block): current step with minutes since it (red −n) + next step countdown; tap → full list (−60 on board, −45 PRM/UM, −40 boarding + prelim loadsheet, −20 APU, −15 offload, −10 PA, −5 doors). Crew brief chip ends at STD−75 so the two don't overlap.
- **Backend** `apps-script/Code.gs`: mail OFP list, calendar, ADS-B, Gemini (several keys in Script Properties `GEMINI_KEY` + `GEMINI_KEYS`, 429/503 back-off, briefing uses flash-lite), translation queue (`trQueue_`/`trWork_` every minute), mailbox auto-reader (`autoOfp_`: AI extracts all NOTAMs from new OFP PDFs, retries), FI DB (`figet/fiput`), shared state (`stput`: atd/zfw/cs/ato, newest wins, ATD also to the clock), briefing (`pkgai`, `pkgpdf`, `sbsave`).

- Flight Assist map (2026-11-20): land canvas padding .15 (iPad Safari blanks canvases over ~16.7 M px); `mapHeal()` redraws after resize / return from background; `mapPad()` / `fitVis()` / `viewAt()` keep the route and aircraft out from under the waypoint column and the bottom cards; ⤢ Whole-route button; service worker caches files one by one (only core files block an update).

- Flight Assist also shows the crew-brief and pre-departure timeline chips (`assist/cbtl.js`, same timings and texts as the panel; return leg = stored OFP from destination back within 36 h via `OFL.entries`). Keep the two copies of `TLS` in sync. Leaving checklist (`CHK`, both panel and assist): appears 20 min before pick-up (STD−135) until every item is ticked (or ✕, or STD−60); not shown on a turnaround; ticks stored per flight on each device (not synced). GPS interference card (`gpsPlan` / `GPS_STEPS`, both panel and assist): DEP airport GNSS NOTAM → STD−60…−20 "POS GPS OFF · TERR OVRD ON · RADIO NAV ENABLE"; after take-off, 15 min from entering the first FIR without a GNSS NOTAM → "GPS ON · RADIO NAV ON · TERR OVRD OFF"; DEST GNSS NOTAM → last 60 min "TERR OVRD ON · GPS OFF · RADIO NAV UPDATE ON · RNP APCH · PROGRESS · RNP 1". The old long DB `gnss` procedure is no longer shown. Panel short brief: `sbReflow()` rebuilds the iPad Today Brief HTML for the phone (label + big value tiles, two per row, long items full width); 🔍 switches to the original page (remembered in `pnl.sbo`). Panel map layers (ALT button → `LAY` r/a/l): 1h 410 nm / 2h 820 nm rings around the aircraft, route airports coloured by EK category (D/A1/A2/CA/EA for the OFP aircraft type), and a "1 h alternates" list at the bottom of the right column (weather → category → distance; tap → short airport card). The EK authorisation table is imported on the iPad and uploaded by `CLOUD.ekUp()` through the existing `sbsave` action as `ofpdata/ZZEKTABLE.sb.html` (private flight-box); the panel downloads it every 6 h when online (`pnl.ek`).

## Data formats for other AIs
- `flight-intel-format.md` (areas / notams / waypoints / procedures) and `提醒规则格式-reminders.md` (reminders: where + timed steps) — copies were sent to the user.

- OFP number (`OFP:34/0/1` → `flight.ofpn` = 34, bigger = newer): Flight Assist keeps every number as its own library entry (key ends with `|34`), uses the newest per flight automatically, shows "OFP 34" in the title and in the flight menu (older ones selectable). Uploads to the cloud carry `meta.ofpn` and are skipped when the cloud already has a bigger number (iPad and phone); downloads only take bigger numbers.
- Revised OFPs (2026-11-20): Lido re-sends with the same file name. Flight Assist mail now goes by attachment id (oldest first, newer overwrites), skips identical text, and reloads the current flight when its OFP changed; cloud sync also re-downloads when the cloud copy is newer and a different length.

- Country contingency (WAC) in Chinese (2026-11-21): backend action `waczh` (names = country names, regions as `R:name`) has Gemini rewrite each section as short plain-Chinese bullets (codes / frequencies / numbers kept), caches in flight-box `fidata/wac.zh.json` keyed `country|heading` with a hash of the English. Panel (`WACZ`, `waczhSync` for countries on legs in the next 48 h) and Flight Assist (`Z2`, on opening the route card) download and show: zh = Chinese only, both = Chinese + small English, en = English. Needs backend ≥ 2026-11-21a (auto-loads within an hour, or POST reload).
- Panel portrait layout (2026-11-21): waypoints in a horizontally scrolling row under the flight number (`#wps`, next FIR first, auto-scrolls to the next point unless swiped in the last 20 s); the right column is hidden so the map is full width; the 1 h alternates list pops up at the map's bottom right and moves above the warning card. Landscape unchanged.
- Panel alternates show bearing from the aircraft (true °, arrow rotated by the true bearing, i.e. pointing at the airport on the north-up map) and distance, with dashed lines on the map. Waypoint list start no longer sticks in the last 12 points; a GPS fix that stays at the same spot for 3 min while gs > 80 kt is ignored (falls back to the plan).
- Logbook (2026-11-21): time fields ranked man 3 > adsb 2 > est 1.5 > fa 1 > plan 0. Backend `lbMerge_` (≥ 2026-11-21b) merges the four times field by field on sync (higher rank wins, same rank → newer), other fields newest entry wins. Panel fetches ADS-B times itself (`lbAdsb`, `?action=logtimes`) for flights landed in the last 3 days on every sync, 📡 button for 7 days; superscripts P / E / A / ✎.
- Panel leg summary SV 4 adds `drw`/`arw` (runways) and `sid` (navlog[1].awy when it looks like a SID, e.g. UDONO2A): the first waypoint shows WADD/09 + SID; before take-off the waypoint row starts at the departure airport and the route shows IATA/ICAO; the top-left status shows the OFP number. PIC staff number: not found in the OFP text (CAPT: is blank) — waiting for the user to say where it is.
- Airport reminders `APN` (panel index.html and assist/cbtl.js, keep in sync): WADD = online Indonesia arrival health declaration + QR code. Shown from STD−24 h to off-block for flights to that airport until ✓ Done (per flight).
- Panel e-ink ghosting (2026-11-21): `inkFlash()` covers the screen black → white → off (~0.45 s) to force a full e-ink refresh; automatic every N min (⚙︎: off / 5 / 10 / 15, default 10, `pnl.ghost`), after closing the sheet / settings / pre-departure board, and ☰ → ◼︎ Refresh screen. When on, html.calm stops the alternating FIR names and other animations.
- Panel before take-off shows the map; the pre-departure board opens with the 🛫 map button (`BOARDV`).
